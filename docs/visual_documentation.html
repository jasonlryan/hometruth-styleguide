Update Management

// Update Detection Flow 1. Scheduled Check (daily/weekly) ├── Query documents with autoUpdate: true ├── Re-scrape original URLs └── Compare content hashes 2. Change Detection ├── Hash comparison ├── Content diff analysis └── Update decision 3. Update Execution ├── Delete old chunks ├── Process new content ├── Re-generate metadata └── Store updated vectors

Metadata Schema

Field Type Description
id string Unique document identifier
name string Document title
category string Legal, Financial, Property Assessment, etc.
tags string[] Searchable keywords
priority string low, normal, high, critical
source string Government, Legal Firm, Manual Upload
url string Original URL (if scraped)
contentHash string SHA-256 hash for change detection
autoUpdate boolean Enable automatic updates
version number Document version number
documentId string User-friendly document identifier
userId string "system" for knowledge base content
fileSize number File size in bytes (if uploaded)
mimeType string MIME type of original file
uploadDate string ISO timestamp of upload
lastUpdated string Last update timestamp

Setup & Configuration

Environment Variables

# Required OPENAI_API_KEY=your_openai_api_key_here PINECONE_API_KEY=your_pinecone_api_key_here # Optional NODE_ENV=development NEXT_PUBLIC_APP_URL=http://localhost:3000 PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium-browser

Pinecone Configuration

{ name: "hometruth-knowledge-base", dimension: 1024, metric: "cosine", embed: { model: "llama-text-embed-v2", fieldMap: { text: "chunk_text" } } }

OpenAI Settings

{ model: "gpt-4o-mini", temperature: 0.3, // For metadata analysis max_tokens: 1000, response_format: { type: "json_object" } }
